🚀 快速开始（3步即可运行）

【第1步】安装依赖
  pip install flask requests

  或使用国内镜像加速：
  pip install flask requests -i https://pypi.tuna.tsinghua.edu.cn/simple

【第2步】配置公众号信息
  编辑文件：wechat_official_account_config.ini
  
  填写以下信息：
  [WECHAT_OFFICIAL]
  appid = 你的公众号AppID
  appsecret = 你的公众号AppSecret
  token = 自定义Token（建议使用随机字符串）

  获取方式：
  • 正式公众号：https://mp.weixin.qq.com/ → 开发 → 基本配置
  • 测试公众号：https://mp.weixin.qq.com/debug/cgi-bin/sandbox (推荐)

【第3步】创建菜单并启动
  # 方式1：使用启动脚本（推荐）
  ./start_wechat_official.sh
  然后选择对应的功能

  # 方式2：手动执行
  python3 wechat_official_menu.py      # 创建菜单
  python3 wechat_official_server.py    # 启动服务器

📖 详细教程

【1】创建简单菜单
  python3 -c "
  from wechat_official_menu import WeChatOfficialMenuManager
  manager = WeChatOfficialMenuManager()
  menu = {
      'button': [
          {'type': 'click', 'name': '点我', 'key': 'CLICK_ME'}
      ]
  }
  manager.create_menu(menu)
  "

【2】创建多级菜单
  查看文件：wechat_official_example.py
  运行：python3 wechat_official_example.py
  选择示例2

【3】上传媒体文件
  # 准备文件
  将图片放到：media/images/my_image.jpg
  
  # 上传获取media_id
  python3 -c "
  from wechat_official_menu import WeChatOfficialMenuManager
  m = WeChatOfficialMenuManager()
  media_id = m.upload_media('./media/images/my_image.jpg', 'image')
  print(f'Media ID: {media_id}')
  "

【4】配置菜单响应
  编辑文件：wechat_official_server.py
  找到函数：handle_menu_click
  添加你的处理逻辑

【5】查看现有菜单
  python3 -c "
  from wechat_official_menu import WeChatOfficialMenuManager
  m = WeChatOfficialMenuManager()
  menu = m.get_menu()
  import json
  print(json.dumps(menu, ensure_ascii=False, indent=2))
  "

【6】删除菜单
  python3 -c "
  from wechat_official_menu import WeChatOfficialMenuManager
  m = WeChatOfficialMenuManager()
  m.delete_menu()
  "

🎯 完整示例

【示例：创建带图片/视频/音频的菜单】

from wechat_official_menu import WeChatOfficialMenuManager

manager = WeChatOfficialMenuManager()

# 定义菜单结构
menu = {
    "button": [
        {
            "name": "📱 多媒体",
            "sub_button": [
                {"type": "click", "name": "📸 查看图片", "key": "SHOW_IMAGE"},
                {"type": "click", "name": "🎬 观看视频", "key": "SHOW_VIDEO"},
                {"type": "click", "name": "🎵 听音频", "key": "SHOW_AUDIO"}
            ]
        },
        {
            "name": "ℹ️ 服务",
            "sub_button": [
                {"type": "click", "name": "关于我们", "key": "ABOUT"},
                {"type": "view", "name": "官方网站", "url": "https://www.example.com"}
            ]
        },
        {
            "type": "click",
            "name": "❓ 帮助",
            "key": "HELP"
        }
    ]
}

# 创建菜单
if manager.create_menu(menu):
    print("✅ 菜单创建成功！")
    print("💡 请在微信公众号中查看")

🔧 配置微信公众平台

【1】登录微信公众平台
  https://mp.weixin.qq.com/

【2】进入开发设置
  左侧菜单 → 开发 → 基本配置

【3】配置服务器
  服务器地址(URL)：http://你的域名:8080/wechat
  令牌(Token)：与配置文件中的token一致
  消息加解密方式：明文模式（或安全模式）
  
  点击"提交"验证

【4】测试菜单
  取消关注后重新关注公众号
  或等待最多24小时生效

⚠️ 常见问题

Q1: 菜单不显示？
A: 取消关注后重新关注，或等待24小时生效

Q2: 点击菜单没反应？
A: 检查服务器是否运行，查看日志文件

Q3: 上传素材失败？
A: 检查文件大小和格式是否符合要求
   图片≤2MB，视频≤10MB，音频≤2MB

Q4: access_token获取失败？
A: 检查AppID和AppSecret是否正确

Q5: 服务器验证失败？
A: 确认Token配置一致，检查服务器日志

💡 使用建议

1. 开发阶段使用测试公众号（免费、方便）
2. 媒体文件提前准备好，注意格式和大小

4. 服务器需要公网IP或使用内网穿透
5. 备份配置文件和重要数据
6. 生产环境使用Gunicorn等WSGI服务器
