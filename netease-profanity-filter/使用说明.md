# 网易云脏字过滤 Java SDK 使用说明

## 项目概述

本项目是一个完整的网易云脏字过滤Java SDK，提供了文本和图片内容审核功能。项目采用Maven构建，支持Java 11+，集成了现代化的HTTP客户端和JSON处理库。

## 核心功能

### 1. 文本内容审核
- 敏感词检测
- 垃圾信息识别
- 政治敏感内容检测
- 支持多种检测场景

### 2. 图片内容审核
- 色情内容检测
- 暴力内容检测
- 政治敏感图片检测
- 支持多种图片格式（JPG、PNG、GIF、BMP、WEBP）

### 3. 多种输入方式
- URL方式：通过图片URL进行审核
- Base64方式：通过Base64编码数据进行审核
- 文件方式：通过本地文件路径进行审核

### 4. 异步处理
- 支持异步API调用
- 批量处理能力
- 高并发场景优化

## 使用示例

### 基本使用

```java
import com.netease.profanity.filter.ProfanityFilterConfig;
import com.netease.profanity.filter.ProfanityFilterService;
import com.netease.profanity.filter.model.FilterResponse;

public class BasicExample {
    public static void main(String[] args) {
        // 1. 创建配置
        ProfanityFilterConfig config = new ProfanityFilterConfig(
            "your_access_key_id",      // 替换为实际的访问密钥ID
            "your_access_key_secret"   // 替换为实际的访问密钥
        );
        
        // 2. 创建服务实例
        ProfanityFilterService service = new ProfanityFilterService(config);
        
        try {
            // 3. 文本审核
            String text = "这是一段需要审核的文本内容";
            FilterResponse textResponse = service.filterText(text, "demo_business");
            
            if (textResponse.isPass()) {
                System.out.println("文本审核通过");
            } else if (textResponse.isReject()) {
                System.out.println("文本审核不通过");
                System.out.println("敏感词：" + textResponse.getSensitiveWords());
            }
            
            // 4. 图片审核
            String imageUrl = "https://example.com/test.jpg";
            FilterResponse imageResponse = service.filterImage(imageUrl, "demo_business");
            
            if (imageResponse.isPass()) {
                System.out.println("图片审核通过");
            } else {
                System.out.println("图片审核不通过");
            }
            
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            // 5. 关闭服务
            service.close();
        }
    }
}
```

### 异步处理示例

```java
import java.util.concurrent.CompletableFuture;

public class AsyncExample {
    public static void main(String[] args) {
        ProfanityFilterConfig config = new ProfanityFilterConfig(
            "your_access_key_id",
            "your_access_key_secret"
        );
        
        ProfanityFilterService service = new ProfanityFilterService(config);
        
        try {
            // 异步文本审核
            CompletableFuture<FilterResponse> textFuture = 
                service.filterTextAsync("异步审核文本", "async_demo");
            
            textFuture.thenAccept(response -> {
                if (response.isPass()) {
                    System.out.println("异步文本审核通过");
                } else {
                    System.out.println("异步文本审核不通过");
                }
            });
            
            // 异步图片审核
            CompletableFuture<FilterResponse> imageFuture = 
                service.filterImageAsync("https://example.com/image.jpg", "async_demo");
            
            imageFuture.thenAccept(response -> {
                if (response.isPass()) {
                    System.out.println("异步图片审核通过");
                } else {
                    System.out.println("异步图片审核不通过");
                }
            });
            
            // 等待所有异步任务完成
            CompletableFuture.allOf(textFuture, imageFuture).join();
            
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            service.close();
        }
    }
}
```

### 批量处理示例

```java
public class BatchExample {
    public static void main(String[] args) {
        ProfanityFilterConfig config = new ProfanityFilterConfig(
            "your_access_key_id",
            "your_access_key_secret"
        );
        
        ProfanityFilterService service = new ProfanityFilterService(config);
        
        try {
            // 批量文本审核
            String[] texts = {
                "文本内容1",
                "文本内容2",
                "文本内容3"
            };
            
            CompletableFuture<FilterResponse[]> textFutures = 
                service.filterTextsAsync(texts, "batch_demo");
            
            FilterResponse[] textResults = textFutures.get();
            
            for (int i = 0; i < textResults.length; i++) {
                System.out.println("文本" + (i + 1) + "审核结果：" + 
                    (textResults[i].isPass() ? "通过" : "不通过"));
            }
            
            // 批量图片审核
            String[] imageUrls = {
                "https://example.com/image1.jpg",
                "https://example.com/image2.jpg",
                "https://example.com/image3.jpg"
            };
            
            CompletableFuture<FilterResponse[]> imageFutures = 
                service.filterImagesAsync(imageUrls, "batch_demo");
            
            FilterResponse[] imageResults = imageFutures.get();
            
            for (int i = 0; i < imageResults.length; i++) {
                System.out.println("图片" + (i + 1) + "审核结果：" + 
                    (imageResults[i].isPass() ? "通过" : "不通过"));
            }
            
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            service.close();
        }
    }
}
```

## 配置说明

### ProfanityFilterConfig 配置项

| 配置项 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| accessKeyId | String | 是 | - | 网易云API访问密钥ID |
| accessKeySecret | String | 是 | - | 网易云API访问密钥 |
| endpoint | String | 否 | https://censor.netease.im | API服务地址 |
| timeout | int | 否 | 30000 | 请求超时时间（毫秒） |
| connectTimeout | int | 否 | 10000 | 连接超时时间（毫秒） |
| debug | boolean | 否 | false | 是否启用调试模式 |

### 配置文件方式

在 `application.properties` 中配置：

```properties
# 网易云API配置
netease.profanity.access-key-id=your_access_key_id
netease.profanity.access-key-secret=your_access_key_secret
netease.profanity.endpoint=https://censor.netease.im

# 超时配置
netease.profanity.timeout=30000
netease.profanity.connect-timeout=10000

# 调试模式
netease.profanity.debug=false
```

## API 参考

### 文本审核方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| filterText(String text) | text: 待审核文本 | FilterResponse | 同步文本审核 |
| filterText(String text, String businessId) | text: 待审核文本<br>businessId: 业务ID | FilterResponse | 同步文本审核（带业务ID） |
| filterTextAsync(String text) | text: 待审核文本 | CompletableFuture<FilterResponse> | 异步文本审核 |
| filterTextAsync(String text, String businessId) | text: 待审核文本<br>businessId: 业务ID | CompletableFuture<FilterResponse> | 异步文本审核（带业务ID） |

### 图片审核方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| filterImage(String imageUrl) | imageUrl: 图片URL | FilterResponse | 通过URL审核图片 |
| filterImage(String imageUrl, String businessId) | imageUrl: 图片URL<br>businessId: 业务ID | FilterResponse | 通过URL审核图片（带业务ID） |
| filterImageBase64(String imageData, String businessId) | imageData: Base64数据<br>businessId: 业务ID | FilterResponse | 通过Base64数据审核图片 |
| filterImageFile(String imagePath, String businessId) | imagePath: 文件路径<br>businessId: 业务ID | FilterResponse | 通过文件路径审核图片 |

### 批量处理方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| filterTextsAsync(String[] texts) | texts: 文本数组 | CompletableFuture<FilterResponse[]> | 批量文本审核 |
| filterTextsAsync(String[] texts, String businessId) | texts: 文本数组<br>businessId: 业务ID | CompletableFuture<FilterResponse[]> | 批量文本审核（带业务ID） |
| filterImagesAsync(String[] imageUrls) | imageUrls: 图片URL数组 | CompletableFuture<FilterResponse[]> | 批量图片审核 |
| filterImagesAsync(String[] imageUrls, String businessId) | imageUrls: 图片URL数组<br>businessId: 业务ID | CompletableFuture<FilterResponse[]> | 批量图片审核（带业务ID） |

## 响应结果说明

### FilterResponse 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 响应码，200表示成功 |
| message | String | 响应消息 |
| action | Integer | 检测结果：0-通过，1-不通过，2-疑似 |
| confidence | Double | 置信度（0-100） |
| sensitiveWords | List<String> | 检测到的敏感词列表 |
| details | List<FilterDetail> | 详细信息 |
| requestId | String | 请求ID |
| processTime | Long | 处理时间（毫秒） |

### 便捷方法

| 方法名 | 返回值 | 说明 |
|--------|--------|------|
| isPass() | boolean | 是否通过检测 |
| isReject() | boolean | 是否不通过检测 |
| isSuspect() | boolean | 是否为疑似内容 |

## 错误处理

### 常见异常

1. **IllegalArgumentException**
   - 原因：参数无效（如文本为空、URL为空等）
   - 处理：检查输入参数的有效性

2. **IOException**
   - 原因：网络请求失败
   - 处理：检查网络连接和API配置

## 性能优化建议

1. **连接池复用**
   - SDK内部使用OkHttp连接池，自动复用连接
   - 建议使用单例模式创建服务实例

2. **异步处理**
   - 对于高并发场景，使用异步API
   - 合理设置线程池大小

3. **批量处理**
   - 对于大量内容，使用批量处理API
   - 减少网络请求次数

4. **超时设置**
   - 根据网络环境调整超时时间
   - 避免过长的等待时间

## 注意事项

1. **API密钥安全**
   - 不要在代码中硬编码API密钥
   - 使用环境变量或配置文件管理密钥

2. **调试模式**
   - 生产环境请关闭调试模式
   - 调试模式会输出详细的请求和响应信息

3. **文件大小限制**
   - 图片文件大小建议不超过10MB
   - 文本长度建议不超过10000字符

4. **支持的格式**
   - 图片格式：JPG、PNG、GIF、BMP、WEBP
   - 文本编码：UTF-8

## 常见问题

### Q: 如何获取API密钥？
A: 请登录网易云控制台，在内容安全服务中申请API密钥。

### Q: 支持哪些图片格式？
A: 支持JPG、PNG、GIF、BMP、WEBP等常见图片格式。

A: 建议实现重试机制和降级策略，确保服务的可用性。

### Q: 批量处理的性能如何？
A: 批量处理采用并发方式，性能优于单个请求的串行处理。

### Q: 如何监控API调用情况？
A: 可以通过日志和响应中的requestId来追踪API调用情况。
