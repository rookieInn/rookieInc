🌐 Spring Boot CORS 测试页面

📋 测试说明

此页面用于测试Spring Boot应用的跨域请求处理。点击下方按钮测试不同的HTTP方法和CORS配置。

注意： 请确保Spring Boot应用已启动在 http://localhost:8080

🔗 可用的API端点

  • GET /api/test - 基础GET请求测试
  • POST /api/test - 基础POST请求测试
  • PUT /api/test/{id} - 基础PUT请求测试
  • DELETE /api/test/{id} - 基础DELETE请求测试
  • POST /api/test/headers - 带自定义请求头的测试
  • GET /api/data - 返回JSON数据
  • GET /cors/method-level - 方法级别CORS测试
  • POST /cors/specific-path - 特定路径CORS测试
  • GET /cors/manual-options - 手动OPTIONS处理测试
  • POST /cors/complex-request - 复杂请求测试
