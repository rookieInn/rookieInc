# 分账程序

一个简单、快速、准确的分账工具，让AA制变得轻松愉快。

## 功能特点

- 🎯 **多种分账方式**
  - 平均分账：所有参与者平均分摊费用
  - 按比例分账：按指定比例分摊费用
  - 自定义分账：手动指定每人应付金额

- 👥 **用户管理**
  - 添加和管理参与分账的用户信息
  - 支持用户邮箱和电话信息

- 📊 **账单管理**
  - 创建和管理分账账单
  - 实时查看分账详情
  - 支持账单描述和备注

- 💰 **支付跟踪**
  - 实时标记支付状态
  - 支付进度统计
  - 支付历史记录

- 📱 **现代化界面**
  - 响应式设计，支持手机和平板
  - 直观的操作界面
  - 美观的Bootstrap样式

- 💾 **数据持久化**
  - SQLite数据库存储
  - 自动保存所有分账记录
  - 支持数据导出

## 快速开始

### 方法一：使用启动脚本（推荐）

1. 确保已安装Python 3.7或更高版本
2. 运行启动脚本：
   ```bash
   python3 start_split_bill.py
   ```
3. 程序会自动安装依赖并启动
4. 浏览器会自动打开 http://localhost:5000

### 方法二：手动启动

1. 安装依赖：
   ```bash
   pip install -r requirements_split_bill.txt
   ```

2. 启动程序：
   ```bash
   python3 split_bill_app.py
   ```

3. 打开浏览器访问：http://localhost:5000

## 使用说明

### 1. 添加用户

1. 点击导航栏的"用户管理"
2. 点击"添加用户"按钮
3. 填写用户信息（姓名必填）
4. 点击"添加"完成

### 2. 创建账单

1. 点击导航栏的"账单管理"
2. 点击"创建账单"按钮
3. 填写账单信息：
   - 账单标题（必填）
   - 总金额（必填）
   - 描述（可选）
   - 选择分账方式
   - 选择参与用户
4. 点击"创建账单"完成

### 3. 查看和管理账单

1. 在账单列表中点击"查看详情"
2. 查看分账详情和支付状态
3. 点击"标记已支付"更新支付状态
4. 查看支付进度统计

### 4. 导出和分享

- **导出账单**：点击"导出账单"下载JSON格式文件
- **分享账单**：点击"分享账单"复制链接或使用系统分享
- **打印账单**：点击"打印账单"打印当前页面

## 分账方式详解

### 平均分账
所有参与者平均分摊总金额，适用于大部分AA制场景。

### 按比例分账
按指定比例分摊费用，适用于按消费比例分账的场景。

### 自定义分账
手动指定每人应付金额，适用于复杂的分账场景。

## 技术架构

- **后端**：Python Flask
- **前端**：HTML5 + CSS3 + JavaScript + Bootstrap 5
- **数据库**：SQLite
- **依赖管理**：pip + requirements.txt

## 数据库结构

### users 表
- id: 用户ID（主键）
- name: 用户姓名
- email: 邮箱
- phone: 电话
- created_at: 创建时间

### bills 表
- id: 账单ID（主键）
- title: 账单标题
- total_amount: 总金额
- description: 描述
- split_type: 分账方式
- created_by: 创建者ID
- created_at: 创建时间

### bill_splits 表
- id: 分账记录ID（主键）
- bill_id: 账单ID
- user_id: 用户ID
- amount: 应付金额
- is_paid: 是否已支付
- paid_at: 支付时间

## 常见问题

### Q: 如何备份数据？
A: 程序使用SQLite数据库，直接复制 `split_bills.db` 文件即可备份。

### Q: 支持多少用户？
A: 理论上支持无限用户，但建议单次分账不超过50人以保证性能。

### Q: 数据安全吗？
A: 数据存储在本地SQLite数据库中，不会上传到任何服务器，完全私密。

### Q: 支持多语言吗？
A: 当前版本仅支持中文界面，后续版本会考虑添加多语言支持。
